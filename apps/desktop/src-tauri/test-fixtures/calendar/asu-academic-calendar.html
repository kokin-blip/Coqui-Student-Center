ASU regularly offers classes in the fall, spring and summer terms with the following components:

Fall and Spring Session A: 
first 7.5-week session

Fall and Spring Session B: 
second 7.5-week session

Fall and Spring Session C: 
full semester (15 weeks plus final exams)

Summer Session A: 
first 6-week session

Summer Session B: 
second 6-week session

Summer Session C: 
8-week session

If a class is scheduled in a session other than Session A, B or C, the drop, add and withdrawal deadlines are prorated based on the length of the class. Check the calendar icon next to each class on your schedule in My ASU for the prorated deadline dates.
