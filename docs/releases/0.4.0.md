# Student Center 0.4.0 — deterministic local planning

This private desktop milestone replaces the prototype earliest-slot planner with a pure, deterministic 14-day Rust scheduler and completes the local planning interface.

## Student-facing changes

- My Day now recommends exactly one currently feasible action, up to two alternatives, deterministic reasons, and a validity window.
- Calendar includes a seven-day visual week and an accessible agenda fallback.
- Tasks can be split into bounded sessions, made indivisible, assigned prerequisites, and constrained by earliest start, deadline, energy, and location.
- Sleep, weekly availability, fixed commitments, travel, transitions, protected time, completed work, and locked plan blocks are respected as hard constraints.
- Work that cannot fit appears as an overload conflict instead of being overlapped or compressed.
- Future flexible plan blocks can be locked and unlocked.
- Late wake-up, task overrun, low energy, canceled commitment, changed deadline, preference changes, and approved imports trigger scoped replanning.
- Profile name, confirmed IANA timezone, weekly availability, and planning preferences remain editable offline.

## Migration notes

- Database schema advances from 7 to 8.
- The additive migration adds plan-session and location metadata plus planner lookup indexes inside a SQLite savepoint.
- Existing profile, academic, import, vault, commitment, and plan data is preserved.
- The same snapshot and effective time produce byte-equivalent plan decisions with stable session identifiers.
