# Coqui Student Center 0.13.0-rc.2

Unsigned prerelease for Windows x64 and Apple Silicon macOS. macOS packages are ad-hoc signed, not notarized.

- Fixes both Grades crashes caused by nullable native grade summaries, adds grade/category editing recovery, scoped route error recovery, and repairs plan-block navigation across destinations.
- Adds opt-in daily task check-in, an inspectable on-time assignment streak, encrypted quick notes, and a course Materials notes organizer. AI source drafts require exact-scope consent and explicit review/save; manual templates stay available offline.
- Adds schema 31 local persistence and backup coverage for student workflows. See [workflow help](../STUDENT_WORKFLOWS.md).
- Adds schedule analysis in Semester Planner, including screenshot/PDF-derived drafts, rhythm and workload checks, and optional BYOK AI analysis.
- Expands onboarding, automatic planning, study-material recommendations, funding discovery, and optional completion celebrations.
- Includes the macOS OCR runtime for screenshot and PDF import, with pinned-source and checksum verification.
- Includes the current professor-rating lookup work. Treat externally sourced ratings as advisory, not as a scheduling or enrollment decision.

The release workflow builds and smoke-tests Windows and macOS installers before uploading the prerelease. macOS uses an ad-hoc signature; on first open, Gatekeeper may require **System Settings → Privacy & Security → Open Anyway**. The build is not notarized and does not include automatic updates.
