# Student Center 0.3.0 — honest first run

This private desktop milestone removes all forced example information from production and establishes the editable, encrypted local profile foundation.

## Student-facing changes

- Fresh installs open a six-step offline onboarding flow instead of a pre-filled My Day.
- Existing 0.2.0 installs receive a one-time review of exact, untouched demo records. Nothing is removed without confirmation.
- Calendar and Academics now open real local records with empty states and create, edit, and delete controls.
- Tasks support course, priority, academic risk, earliest start, energy, location, splitting, session limits, and dependencies.
- Commitments support travel buffers, location, and protected time.
- Planning preferences and weekly availability persist locally and trigger replanning.
- Local profile deletion requires an exact confirmation and points students to encrypted backup first.

## Migration notes

- Database schema advances from 6 to 7.
- Profile migration is additive and protected by a SQLite savepoint.
- The legacy `courses.source_uid` uniqueness constraint is rebuilt as a partial unique index so multiple manual courses can use an empty source identifier.
- Existing canonical data is preserved. Demo cleanup is a separate user-confirmed transaction.
