`%APPDATA%\app.studentcenter.desktop` and
`%LOCALAPPDATA%\app.studentcenter.desktop` before installing, so the smoke test

## Migration to schema 13

The one step that cannot be checked on a fresh profile. Install **0.9.2** first,
complete setup, import a document, then upgrade in place to 0.10.0 and confirm:

| Check | Result |
|---|---|
| Existing profile opens without a re-key prompt | _yes/no_ |
| `PRAGMA user_version` reports 13 | _yes/no_ |
| Documents imported under 0.9.2 still list and open | _yes/no_ |
| Their candidates still show evidence | _yes/no_ |
| Pending candidates approved before the upgrade are still approved | _yes/no_ |

The last two matter because 0.10.0 is the release that fixed
`get_document_evidence` reading past the end of its own `SELECT`, and the one
that added the shred flag those queries now filter on.
