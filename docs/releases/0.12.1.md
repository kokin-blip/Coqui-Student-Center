# Coqui Student Center 0.12.1

Unsigned desktop prerelease for Windows x64 and Apple Silicon macOS.

- Completes the polished Comfy and Compact desktop experiences.
- Makes pending Canvas imports directly reviewable and sends approved coursework to Work.
- Adds optional linked to-dos for imported calendar events.
- Fixes form, control, and review-dialog alignment across both interface modes.

Windows may show SmartScreen and macOS may require **Privacy & Security → Open Anyway**.
