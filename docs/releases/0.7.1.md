# Coqui Student Center 0.7.1 — School-specific setup

## What changed

- Added school-specific campus choices to onboarding, beginning with Arizona State University: Tempe, Downtown Phoenix, West Valley, Polytechnic, and online/multi-campus.
- Added official registrar-backed academic-term presets. ASU currently includes Fall 2026, Spring 2027, and Fall 2027 Session C dates with finals information and visible source labels.
- Selecting ASU now replaces placeholder term dates with the first sourced term while keeping every date editable.
- Unsupported institutions no longer receive guessed semester dates; the app clearly asks the student to enter dates from the institution registrar.
- Added a typed, allowlisted institution setup provider contract and native command so additional schools can be added without arbitrary web scraping.

## Source and update notes

- ASU campus choices are sourced from `https://campus.asu.edu/`.
- ASU term dates are sourced from `https://registrar.asu.edu/academic-calendar`.
- Official calendars can change. The app identifies the source and asks students to verify dates before finalizing.

## Distribution notes

- Windows x64 ships as an unsigned NSIS private-beta installer.
- Browser output remains limited to development and automated interface checks.
