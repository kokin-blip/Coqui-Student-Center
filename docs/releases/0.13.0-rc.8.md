# Coqui Student Center 0.13.0-rc.8

Apple Silicon macOS prerelease. This release contains a macOS DMG and its SHA-256 checksum only.

- Adds ChatGPT subscription sign-in as the primary AI connector in Settings and onboarding. Authorize Coqui in your system browser, choose a model available to your account, and manage your allowance in ChatGPT Settings → Usage. Account and workspace eligibility apply.
- Keeps ChatGPT credentials in the OS credential vault, with verified identity, PKCE, renewable sessions, account selection, cancellation, and explicit disconnect. AI requests remain subject to Coqui’s existing consent and review controls. OpenAI, Anthropic, and Gemini API-key connectors remain available.
- Includes the calendar fixes since rc.7: classes respect no-class dates, resizing recomputes remaining work, and undo restores the complete previous plan without overwriting newer changes.
- Updates release checks for schema 33 and removes time-of-day and stale-block assumptions from calendar test fixtures.
- Fixes macOS Hardened Runtime blocking the bundled PDF renderer and adds signed-package OCR probes to the macOS release gate.

The DMG includes the verified local OCR runtime. The app is ad-hoc signed and is not notarized. On first open, macOS may require **System Settings → Privacy & Security → Open Anyway**. Automatic updates are not enabled in this prerelease.

Live ChatGPT sign-in and subscription inference require authorization from an eligible account; automated connector checks use synthetic identities and local HTTP fixtures.
