# Coqui Student Center 0.7.0 — Experience refresh

## What changed

- Reorganized the installed app around Today, Timetable, Assignments, Courses, and More.
- Added a persistent Quick Add flow, assignment/exam kinds, instructors, recurring class meetings, and academic no-class events.
- Replaced the six-step first run with a four-stage, autosaving local setup for profile, institution and term, courses and meetings, and weekly rhythm.
- Added operating-system timezone detection, a searchable fallback list, source-labeled course suggestions, duplicate/meeting conflict feedback, and light/dark/system appearance settings.
- Added the vector Coqui frog-and-book identity and generated Windows, macOS, tray, and PNG icon assets.
- Removed production sample seeding. Exact untouched legacy samples are moved into an encrypted, recoverable quarantine before the interface loads; edited and uncertain data is preserved.
- Expanded planner inputs with recurring classes and academic no-class events while keeping the local deterministic planner authoritative.

## Migration notes

- Schema 11 is additive and transactional.
- Legacy sample detection requires both known IDs and exact untouched fingerprints.
- Quarantined records are excluded from planning and normal workspace queries. They can be restored or permanently purged from **More → Data Recovery**.
- Existing courses, assignments, commitments, imports, plans, vault documents, and account data are preserved.

## Distribution notes

- Browser output remains for development and automated interface checks only.
- Windows x64 ships as an unsigned NSIS private-beta installer.
- Apple Silicon macOS builds remain unsigned/ad-hoc private-beta artifacts until signing and notarization credentials are available.
