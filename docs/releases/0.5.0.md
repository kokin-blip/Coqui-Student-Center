# Student Center 0.5.0 — reinforced local services

Milestone 3 strengthens imports, Canvas, reminders, and optional managed AI while keeping the offline planner authoritative.

## Included

- Searchable encrypted document library, desktop drag-and-drop, import history, and source-evidence reopening.
- DOCX paragraph and PPTX slide provenance fixtures in addition to the existing PDF, OCR, image, CSV, XLSX, and ICS corpus.
- Recoverable Canvas token revocation plus hourly checks for connections due for daily reconciliation.
- Restart-safe reminder idempotency, quiet hours, snooze, dismiss, and generic lock-screen content.
- Account-, connectivity-, and consent-gated managed AI with strict structured responses and review-only candidates.
- Content-free AI invocation metadata; prompts and excerpts are neither stored nor logged by the service.
- A Windows DPAPI-protected device-key file that prevents Credential Manager session failures from crashing fresh installations. Existing Credential Manager keys migrate on first successful access.

## Migration notes

- Database schema advances additively from version 8 to 9 by creating the content-free `ai_invocations` audit table.
- Canonical academic data, vault objects, plans, credentials, and prior imports are preserved.
- Windows installs create `device-master-key.dpapi`; it contains only an OS-protected ciphertext blob, never the master key in plaintext.
- A legacy encrypted profile whose original Credential Manager entry is temporarily unavailable is left untouched and reports that the Windows credential must be accessible; the app never replaces the key or database.
