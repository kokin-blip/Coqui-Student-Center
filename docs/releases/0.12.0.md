# Coqui Student Center 0.12.0

**Unsigned desktop prerelease for Windows x64 and Apple Silicon macOS.**

## What changed

- Canvas calendar feeds now import useful events independently, accept Canvas-specific date parameters, preserve date-only precision and locations, and send zero-duration deadlines to review instead of rejecting the entire feed.
- Scholarship Center adds public ASU discovery, saved opportunities, application tracking, encrypted requirement-file review, deadline planning, draft autosave/version history, reusable stories, and consent-based writing feedback.
- The desktop interface now uses the frog-face Coqui identity, feature-owned Today, Calendar, Work, Courses, Study, Scholarships, and Settings workspaces, System/Light/Dark themes, Comfortable/Power density, reduced-motion behavior, and desktop window reflow down to 320px.
- Canvas, AI providers, account and sync, backups, privacy, reminders, updates, and recovery open as nested Settings pages instead of administrative modals.
- Schedule import supports multi-photo correction, crop/rotation/perspective controls, rotating schedules, ICS locations, duplicate cleanup, and opt-in legacy commitment collapse.
- Schema 25 remains additive and preserves existing encrypted profiles and backups. Canvas and AI credentials remain in the operating-system credential vault and are cleared on restore.

## Installation warnings

- Windows is not Authenticode-signed and may show a Microsoft Defender SmartScreen warning.
- macOS uses an ad-hoc bundle seal but is not Developer ID signed or notarized. Open it through **System Settings → Privacy & Security → Open Anyway** when Gatekeeper blocks the first launch.
- Automatic updates are disabled in this unsigned build. Download later prereleases manually from GitHub.

## Certification disclosure

The release workflow builds and smoke-tests both packaged installers with pinned OCR resources before publishing either artifact. Automated TypeScript, contract, cloud, Rust, accessibility, catalog, calendar, migration, backup, and package checks are required.

The following credentialed checks are not claimed by this prerelease unless separately recorded in the release audit:

- live Canvas installed-app testing with a newly regenerated private feed URL;
- paid OpenAI, Anthropic, and Gemini requests;
- live Supabase deployment and RLS certification.

The public ASU Scholarship source adapters passed live source certification. Mobile applications and widgets remain deferred; the narrow layout supports resized and accessibility-magnified desktop windows only.
